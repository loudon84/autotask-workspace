# 天地伟业对账单流程（v3.0）实施计划

依据：[project-docs/prd/AutoTask v3.0 业务需求-天地伟业对账单.md](project-docs/prd/AutoTask%20v3.0%20业务需求-天地伟业对账单.md)（已定稿，22 项确认记录）。

> **For agentic workers:** 按任务序号顺序执行；每完成一个任务打勾（`- [x]`）。各任务自包含，可直接分配子代理执行。
>
> **需求基线**：`project-docs/prd/AutoTask v3.0 业务需求-天地伟业对账单.md`（已定稿，22 项确认记录）
>
> **数据库红线（AGENTS.md）**：Alembic 迁移文件只编写、**不执行**。任何 `alembic upgrade` 必须等用户明确授权后才能运行。

**Goal:** 在现有 v2.x 流程实例框架上落地「天地伟业对账单」场景：生成对账单（SDMS 校验 → SRM 生成 → 本地落表）+ 未对账对账单处理（发票扫描上传 → 人工核对 → 提交审核 → 完成）。

**Architecture:** 复用 `process_instances` 主任务模式：新增 `process_code = srm_tiandi_statement` + 4 个新阶段；每个用户动作 = 一个 `automation_tasks` 子任务 + `rpa_runs`，Engine Worker 拉单执行 4 个新 Flow，finish 回调推进阶段。本地新增 `statement_bills` 表存对账单头（**不存收货明细**）。SDMS 金额校验由 service 直连 HTTP（无认证）。

**Tech Stack:** service = Python 3.12 + FastAPI + SQLAlchemy 2.x async + Alembic + httpx；rpa-flows = Engine 托管 Playwright（`flow.py:run(ctx)`）；app = Electron + React + TanStack Router/Query + shadcn/ui + Tailwind v4。

**状态机（落库字段）：** `check_status`（**DRAFT 待生成** / 未对账 / 已对账 / 已作废）× `invoice_status`（未上传/已上传/审批中）。待生成是本系统草稿。SDMS 通过即落 DRAFT；SRM 成功 → 未对账；失败仍为 DRAFT，只记 `last_error`。

from sqlalchemy import Column, String, Numeric, Date, Text
from app.models.base import BaseModel

class StatementBill(BaseModel):
    """天地伟业对账单头表。只跟踪本系统创建的对账单；不存收货明细。"""
    __tablename__ = "statement_bills"

    tenant_id = Column(String(64), nullable=False, index=True)
    process_instance_id = Column(String(36), nullable=False, index=True)  # 关联主任务
    check_date = Column(Date, nullable=False)          # SRM 创建对账单日期（匹配键之一）
    check_amount = Column(Numeric(18, 2), nullable=False)  # 可立账价税合计（匹配键之一）
    check_status = Column(String(16), nullable=False, default="UNCHECKED")   # UNCHECKED/CHECKED/VOID
    invoice_status = Column(String(16), nullable=False, default="NOT_UPLOADED")  # NOT_UPLOADED/UPLOADED/REVIEWING
    invoice_no = Column(String(256), nullable=True)        # 上传后从 SRM 页面读回
    invoice_amount = Column(Numeric(18, 2), nullable=True) # 上传后从 SRM 页面读回
    portal_account_id = Column(String(36), nullable=False)
    sdms_check_head_id = Column(String(32), nullable=True) # SDMS 校验命中的 check_head_id
    last_error = Column(Text, nullable=True)               # 最近一次操作失败原因

```python
# service/app/services/sdms_client.py
import httpx
from datetime import date, datetime

SDMS_URL = "http://api.qywx.smart-core.com.cn/sdms/ar_check/view_doc_srm"
CUSTOMER_SITE = "C007193-01_104"  # 天地伟业固定值

async def fetch_check_amount(today: date) -> float | None:
    """查询当月 SDMS 对账总金额。返回 None = 未找到/接口异常（由调用方提示人工匹配）。"""
    first = today.replace(day=1)
    if today.month == 12:
        nxt = today.replace(year=today.year + 1, month=1, day=1)
    else:
        nxt = today.replace(month=today.month + 1, day=1)
    last = nxt - timedelta(days=1)
    params = {
        "create_date_s": f"{first:%Y-%m-%d} 00:00:00",
        "create_date_e": f"{last:%Y-%m-%d} 23:59:59",
        "custom_son_code": CUSTOMER_SITE,
    }
    async with httpx.AsyncClient(timeout=15) as client:
        resp = await client.get(SDMS_URL, params=params)
        resp.raise_for_status()
        payload = resp.json()
    if payload.get("code") != 1 or not payload.get("data"):
        return None
    return float(payload["data"][0]["check_amount"])
```
