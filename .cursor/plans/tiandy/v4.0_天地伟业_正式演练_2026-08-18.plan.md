# v4.0 天地伟业正式 SRM 演练 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把天地伟业客户订单、对账单切到正式 SRM（`https://supplier.tiandy.com`），在不写对方数据的前提下把两条链尽量跑全。

**Architecture:** Binding `dryRun=true` 经 Task 租约传到 Engine `ctx.config`。写步骤定位到保存/签章/生成/提交按钮后停下，网络层再拦一遍非登录写请求。finish 钩子看到 `committed: false` 时不推进阶段，只写 `summary.drill`。Client 显示「演练未提交」。缺待签章时用影子实例，不假装 SRM 有单。**SDMS 测试环境真写**（建销售订单、上传合同附件），`dryRun` 只拦对 SRM 的写。

**Tech Stack:** rpa-engine Playwright Runtime；rpa-flows `flow.py:run(ctx)`；service FastAPI + SQLAlchemy；app Electron + React。无新列、不执行 DDL。

**Spec:** [project-docs/prd/AutoTask v4.0 天地伟业.md](../../project-docs/prd/AutoTask%20v4.0%20天地伟业.md)

**红线：** 不保存交期、不签章、不点生成对账单、不提交审批。凭据不进 Git / 文档 / 日志。演示门户 Binding 不动。**SDMS 测试环境允许真写。**

```python
from collections.abc import Mapping

WRITE_METHODS = {"POST", "PUT", "PATCH", "DELETE"}
LOGIN_MARKERS = ("/login", "/captcha", "/auth", "/oauth", "/verify")
UPLOAD_MARKERS = ("/upload", "/scan", "/invoice", "/attach")


def is_dry_run(ctx) -> bool:
    config = getattr(ctx, "config", None)
    if isinstance(config, Mapping) and bool(config.get("dryRun") or config.get("dry_run")):
        return True
    raw = getattr(ctx, "input", None)
    return isinstance(raw, Mapping) and bool(raw.get("dryRun") or raw.get("dry_run"))


def should_block_write(method: str, url: str, *, allow_upload: bool = False) -> bool:
    verb = (method or "GET").upper()
    if verb not in WRITE_METHODS:
        return False
    target = (url or "").lower()
    if any(marker in target for marker in LOGIN_MARKERS):
        return False
    if allow_upload and any(marker in target for marker in UPLOAD_MARKERS):
        return False
    return True


async def install_write_guard(page, *, dry_run: bool, allow_upload: bool = False) -> None:
    if not dry_run or page is None:
        return

    async def handler(route):
        request = route.request
        if should_block_write(request.method, request.url, allow_upload=allow_upload):
            await route.abort("blockedbyclient")
            return
        await route.continue_()

    await page.route("**/*", handler)
```

在 `runtime/__init__.py` 导出 `is_dry_run`、`install_write_guard`。

def output_uncommitted(run) -> bool:
    output = run.output if isinstance(run.output, dict) else {}
    return output.get("committed") is False


def merge_drill(instance, *, step: str, blocked_action: str, shadow: bool = False) -> None:
    summary = loads_json(instance.summary, {})
    if not isinstance(summary, dict):
        summary = {}
    prev = summary.get("drill") if isinstance(summary.get("drill"), dict) else {}
    summary["drill"] = {
        "uncommitted": True,
        "shadow": bool(prev.get("shadow") or shadow),
        "step": step,
        "blockedAction": blocked_action,
        "at": datetime.now(UTC).isoformat(),
    }
    instance.summary = dumps_json(summary)
