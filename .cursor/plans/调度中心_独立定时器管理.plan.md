# 调度中心：独立定时器管理 Implementation Plan

> **For agentic workers:** 按任务勾选实施。未口头授权不得执行 DDL。不要自动 commit。不要在本计划里实现任何具体业务到期逻辑。

**Goal:** 做出一套可维护的定时器管理（档案、开关、cron、到点通知），调度中心只管理这些。

**Architecture:** 定时器是独立行：名称、启用、cron、不透明「指向」。常驻循环加载启用行，到期只调用注册表 `notify(指向)`。注册表本期为空（或仅测试桩）；具体任务以后自己 `register` + 登记默认行。调度中心 UI 只改名称/开关/cron，不展示指向、门户、Binding。

**Tech Stack:** Task FastAPI + SQLAlchemy + 现有 `CronSchedule`；Client 现有调度中心路由改数据源。

**依据:** `project-docs/prd/AutoTask 调度中心.md`

**明确不做（本计划）：** 任何到期后的业务（扫单、回签、匹配交货计划、调接口等）；Binding 插 job；为某个任务再写一套调度器；执行 Alembic。

**现网风险:** 实施后调度中心不再按 Binding 维护旧 `scheduler_jobs`。旧 Binding 开火循环可暂时并行以免现网立刻停，但不在新 UI 出现。把旧任务迁到「登记 + 入口」是**以后的任务开发计划**，不写在这里。

### Task 2: 什么时候触发（内核循环）

**Files:**
- Create: `service/app/services/timer_registry.py`
- Create: `service/app/services/timer_scheduler.py`
- Test: `service/tests/test_timer_scheduler.py`

规则（与现网 cron 语义对齐，不发明新语法）：

- 只加载 `enabled=true` 且未删除的行
- cron 变更则重算下次，**不补跑**上一拍
- 到点：`await timer_registry.notify(job.target)`；无注册入口则记一条 info，**不算失败、不重试补跑**
- `notify` 里入口抛错：记 exception，不影响其它定时器
- 热加载：每个 tick 读库，最长约 30 秒

`timer_registry.py` 形状：

```python
_registry: dict[str, Callable[[], Awaitable[None]]] = {}

def register(target: str, fn: Callable[[], Awaitable[None]]) -> None:
    _registry[target] = fn

async def notify(target: str) -> None:
    fn = _registry.get(target)
    if fn is None:
        logger.info("timer due, no listener target=%s", target)
        return
    await fn()
```

本计划**不**往 registry 里注册任何业务函数。单测用临时 `register("t1", spy)`。

- [ ] 单测：禁用行不到点不 notify
- [ ] 单测：到点调用 spy；未注册只打日志
- [ ] 单测：改 cron 后 next 是未来槽，不立刻当补跑
- [ ] 实现 `TimerScheduler`，在 `service/app/main.py` lifespan `start`/`stop`（与现 JobScheduler 并列，直到旧循环另案拆除）
