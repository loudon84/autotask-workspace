# BOE‑SRM 发票箱单自动化完整需求文档

> 文档用途：直接复制全部内容粘贴至 Cursor，生成 Playwright / Selenium Python自动化代码
> 页面地址：`bsrm.boe.com/invoicePackingList/#/invoice-detail?isCreate=true&isEdit=true&isPurchase=true`

## 一、页面整体结构

整个单据页面分为 4 个区域：

1. 基本信息（顶部表单）
2. 项目信息（表格区，新增行会唤起【采购凭证查询】弹窗）
3. 附件信息（附件上传表格）
4. 备注信息

> 弹窗说明：**采购凭证查询弹窗属于网页DOM弹窗，非Windows系统弹窗，可以直接网页元素定位**；文件上传弹出的文件选择窗口为 Windows系统弹窗，浏览器无法直接控制，需 pyautogui 桌面模拟。

## 二、完整主业务操作流程

```
1. 浏览器访问发票箱单新建/编辑页面
2. 【基本信息区】填写头部表单字段
3. 滚动页面向下，定位【项目信息】表格
4. 循环导入项目表格行（通过采购凭证弹窗选择）
    4‑1. 点击项目信息表格【新增】按钮，唤起【采购凭证查询】弹窗
    4‑2. 在弹窗内输入采购订单号，搜索对应PO数据
    4‑3. 勾选搜索结果行左侧复选框
    4‑4. 点击弹窗【保存】，弹窗自动关闭，数据回填项目信息表格
    4‑5. 回填后，可手动修改【本次开票数】等字段
    4‑6. 循环执行直到所有项目行录入完成
5. 继续向下滚动页面，定位【附件信息】表格
6. 循环上传PDF附件
    6‑1. 点击附件表格【新增】按钮，生成一条空白附件行
    6‑2. 文件类型下拉框选择类型（箱单 / 发票 / 提运单 / 双签PO/协议）
    6‑3. 唤起上传按钮，弹出Windows文件选择弹窗
    6‑4. 在系统弹窗文件名输入框填入PDF完整路径
    6‑5. 点击【打开】完成文件上传
    6‑6. (可选)填写备注
    6‑7. 循环上传所有附件
7. 全部录入完毕，校验页面数据，提交保存整张单据
```



## 三、弹窗：采购凭证查询详情说明



### 弹窗触发方式

点击【项目信息】‑【新增】按钮弹出

### 弹窗控件清单

1. 查询筛选区
  - 采购订单号输入框：`请输入采购订单号`
    - 物料编码输入框：`请输入物料编码`
    - 搜索按钮
    - 清空按钮
    - 展开下拉按钮
2. 查询结果表格列
  - 复选框、序号、工厂、采购订单号、行项目、物料编码、物料名称、订单数量、订单单位、BOE采购、订单创建日期、付款条款
3. 弹窗按钮
  - 保存：勾选行后点击，回填数据、关闭弹窗
    - 右上角关闭(X)：放弃选择，关闭弹窗



### 弹窗自动化子流程‑按PO搜索导入

```
1.等待弹窗完全加载渲染
2.采购订单号输入框填入目标PO编号；物料编码留空
3.点击搜索按钮，等待结果表格刷新加载完毕
4.定位搜索返回结果行，勾选该行复选框
5.点击【保存】按钮
6.等待弹窗消失，等待项目信息表格完成数据回填
```
