## Git 交接规则

1. 开始工作前记录分支、HEAD、remote 和 dirty 文件。
2. 配置文件、凭据、Artifact、ZIP、截图、缓存和构建产物不进源码提交。
3. 提交信息使用简体中文说明影响范围、测试和风险；仓库现行约定若要求英文 Conventional Commit 前缀，可采用“前缀 + 中文摘要”。
4. 无上游写权限时推送个人 Fork 的 `v0.1`，再由上游同事 cherry-pick、拉取分支或创建 PR。
5. 禁止对有未提交工作的目录执行 `reset --hard` 或强制覆盖。
