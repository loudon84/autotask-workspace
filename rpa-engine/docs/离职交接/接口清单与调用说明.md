# 接口清单与调用说明

Engine `0.6.0` 公开 17 个入站路由，直接返回 JSON，不使用 Task 的 `{code,data}` 信封。

## 健康接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/health/live` | 进程存活 |
| `GET` | `/health/ready` | 已启用的必需依赖 |

## Flow Registry

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/v1/flows` | Flow 列表 |
| `POST` | `/api/v1/flows/packages` | 上传 ZIP 并创建 DRAFT |
| `GET` | `/api/v1/flows/{rpaFlowId}` | Flow 详情 |
| `GET` | `/api/v1/flows/{rpaFlowId}/versions` | 版本列表 |
| `POST` | `/api/v1/flows/{rpaFlowId}/disable` | 禁用 Flow |
| `POST` | `/api/v1/flows/{rpaFlowId}/rollback` | 回滚发布状态 |
| `POST` | `/api/v1/flow-versions/validate-binding` | 精确 Binding 校验 |
| `GET` | `/api/v1/flow-versions/{flowVersionId}` | 版本详情 |
| `POST` | `/api/v1/flow-versions/{flowVersionId}/validate` | 重新校验 ZIP |
| `POST` | `/api/v1/flow-versions/{flowVersionId}/publish` | 发布版本 |
| `POST` | `/api/v1/flow-versions/{flowVersionId}/deprecate` | 弃用版本 |
| `POST` | `/api/v1/flow-versions/{flowVersionId}/disable` | 禁用版本 |
| `GET` | `/api/v1/flow-versions/{flowVersionId}/package` | 307 签名下载跳转 |

## Worker 观察接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/v1/workers` | Worker 列表 |
| `GET` | `/api/v1/workers/{workerId}` | Worker 详情 |

## 请求规则

所有 `/api/v1/**` 请求要求 `X-Actor-Id`；TENANT Flow 还要求 `X-Tenant-Id`。这些 Header 是测试审计上下文，不是生产鉴权。

Engine 不提供 `/run`、`/execute` 或 `/flows/{id}/run`。运行入口在 Task，Engine 通过 Worker lease 主动领取 Run。

统一集合为 `postman/AutoTask_RPA_Engine_v0.5.0.postman_collection.json`。文件名保留 `v0.5.0`，当前 `0.6.0` 没有改变上述 17 个路由。写 Registry 前设置 `allow_registry_writes=true`；生命周期操作还需 `allow_lifecycle_changes=true`。

Binding 校验即使业务失败也可能返回 HTTP 200，必须检查 `valid` 和 `reasonCode`。包下载检查 307 和 `Location`，不得记录短时签名 URL。
