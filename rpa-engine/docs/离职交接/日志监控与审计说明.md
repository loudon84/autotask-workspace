# 日志、监控与审计说明

## 日志

Engine 向标准输出写结构化 JSON，核心字段为：

```text
timestamp level logger message runId workerId flowVersionId
```

启动日志只输出安全配置快照。常见敏感字段、Authorization 和签名参数会脱敏，但调用方仍不得把秘密写入 message、事件或异常文本。

- Windows：日志在运行 Engine 的 PowerShell 窗口；长期运行由受控服务收集。
- Linux：

```bash
sudo journalctl -u nodeskclaw-rpa-engine.service -f
```

日志平台应保留 JSON 字段。

## 建议监控项

- live/ready 及 dependency 状态。
- Worker 心跳、槽位和 OFFLINE 数量。
- lease、renew、过期和拒绝数量。
- Run 终态、耗时、重试和超时。
- 浏览器启动失败、Runtime 磁盘使用率。
- EVENT/FINISH Outbox 待发送、重试、死信和最老记录年龄。
- Artifact 上传/metadata 成功率。
- PostgreSQL 连接、容量、慢查询和锁。

紧急告警包括 ready 持续失败、重复业务写入、凭据泄露和数据损坏；高优先级告警包括 Worker 离线、Outbox 持续积压、RUNNING 超限和 Artifact 大面积失败。告警只携带环境、workerId、runId、flowVersionId、errorCode 和时间。

## 审计来源

- `rpa_flow_release_audits`：Flow 生命周期。
- `rpa_execution_attempts`：执行尝试和终态。
- `rpa_callback_outbox`：EVENT/FINISH 投递。
- Task Run Events 和 Artifact 元数据：业务步骤与证据。
- Auth/Task 审计：用户、Portal、模板、Binding 和任务操作。

排障按 `runId` 串联 Task Run、Engine attempt、Outbox、事件和 Artifact。

## 保留与导出

- 保留周期由环境和合规负责人登记。
- 导出前再次做秘密扫描。
- Trace、截图和下载文件属于 Artifact，不混入普通日志。
- 生产日志对外共享前必须完成脱敏审批。
