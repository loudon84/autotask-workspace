# SRM 回签状态只读探测（rpa_flow_srm_check_reply_status 1.1.3）

> **适用门户：正式门户**（`https://supplier.tiandy.com`，无 `data-rpa`）。**不能绑演示门户**。演示门户继续用 `1.0.1`。

登录 → 打开订单详情 → 读取回复状态 → 输出 `replyStatus`。**禁止**点击签章或任何写操作。

## 1.1.3 变更

正式详情没有演示站那种 `.el-tag`。有「查看签章」即视为已回签；否则在页面上找「回复状态」旁的 `已回签/待回签/待签章`。

## 1.1.2 变更

打开详情与建单相同：点冻结列可见「详情」，用「查看签章」或「导出订单明细」确认已进详情。
