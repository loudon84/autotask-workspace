# SRM 回签状态只读探测（rpa_flow_srm_check_reply_status 1.1.4）

> **适用门户：正式门户**（`https://supplier.tiandy.com`，无 `data-rpa`）。**不能绑演示门户**。演示门户继续用 `1.0.1`。

登录 → 订单列表按 **回复状态=已回签 + 订单编号** 查询 → 有行则进详情 → 输出 `replyStatus=已回签`。进了详情就不再读状态。**禁止**点击签章。

## 1.1.4 变更

列表搜索条件就是已回签和单号。搜到并打开详情，即已回签；详情里不再找 `.el-tag` 或回复状态文案。列表没有该行则输出 `待回签`，不进详情。
