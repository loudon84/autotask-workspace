# 供应商门户双方签章合同上传 Flow

版本：`1.3.1`

> **适用门户：正式门户**（`https://supplier.tiandy.com`，无 `data-rpa`）。演示站继续用 `1.2.5`。本包只下载已回签合同并上传到我们的测试 SDMS，**不点** SRM 保存/签章/提交。Binding **不要**设 `dryRun`（那会拦住 SDMS 上传）。

本 Flow 登录正式供应商门户，按订单号打开详情，点击「**查看签章**」下载双方签章合同，再上传到 SDMS 销售订单附件接口。

打开列表详情时点冻结操作列里可见的「详情」，避免点到隐藏副本后停在列表。详情以「查看签章」可见作为已进入确认。

## 1.3.1 变更（相对 1.3.0）

正式站「已回签」在订单列表的「回复状态」列，不是演示站详情上的 `.el-tag`。进详情前按表头读这一列；确认已回签后再点「查看签章」下载。

## 1.3.0 变更（相对 1.2.5）

正式门户专用：OCR 登录、`#/order/list`、无 `data-rpa`。合同入口是详情上的「查看签章」。
